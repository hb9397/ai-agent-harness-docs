# Korean AI/Translationese Refinement Taxonomy

`im-not-ai` v2.3.0의 핵심 방향을 하네스 문서용으로 축약·재구성한 참고 분류다.

| ID | 유형 | 점검 포인트 |
|---|---|---|
| A | 번역투 | `~에 의해`, `~에 있어서`, `~를 통해` 남용 |
| B | 과한 명사화 | 동사로 풀 수 있는 `수행`, `진행`, `처리` 반복 |
| C | 기계적 병렬 | `첫째/둘째/셋째`, 동일 길이 문장 반복 |
| D | AI 관용구 | `결론적으로`, `시사하는 바가 크다`, `중요한 역할을 한다` |
| E | 피동·사동 남용 | 주체가 사라진 문장 |
| F | 과도한 완곡 표현 | 책임·의무 수준이 흐려지는 표현 |
| G | 문서 리듬 불균형 | 모든 문장이 비슷한 길이와 구조로 반복 |

이 분류는 진단 보조용이다. 분류에 맞춘다는 이유로 의미나 요구사항을 바꾸면 안 된다.
