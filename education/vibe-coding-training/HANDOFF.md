## 다음 작업 우선순위

### 🥇 A. ③덱 (실적용) 제작 — 가장 큰 미완료
**설계**: `00_교육자료_설계.md` §6에 골격 있음.
**구성 (권장)**:
- 열기: superpowers 소개 (대표 스킬 2~3개만 — `brainstorming`, `commit` 등)
- 나의 하네스: 이 레포를 "같은 원리 다듬은 버전"으로 (**단, 나의 하네스는 §7 O5에서 "보류(파킹)" 상태** — ①덱 완성 후 확장할지 재판단)
- 클라이맥스: `.md` 공통 규격 회수 (§1 주장 마지막 회수)
- 부가: MCP / Plugin (superpowers + Notion)
- 데모 진입 표지 → **라이브 데모는 슬라이드 X, 별도 `.md` 대본**

**착수 방법 두 가지**:
- (a) ②덱 base.pptx를 새 워크스페이스에 복사 → sldIdLst 비우기 → 필요한 만큼 add_slide로 복제 → 콘텐츠 재작성 (이번 ①덱에서 쓴 방식 그대로)
- (b) pptxgenjs로 처음부터 (설치 필요)

**⚠️ 함정 하나 남김**: `<p:cxnSp>`(connector) 안에는 **`prst="line"`만 넣는다.** `downArrow` 같은 preset은 반드시 `<p:sp>` 안에 넣기. ①덱 slide16에서 이걸로 PowerPoint COM 오픈이 계속 실패했음.

## 환경 재현 — 다른 PC에서 pptx 편집·QA에 필요한 것

**필수**:
- Python 3 + `python-pptx`, `defusedxml`
- PowerPoint (Office 16+) — 렌더 QA용 (COM 자동화)
- Git

**PowerShell 렌더 스크립트** (재사용):
```powershell
$pp = New-Object -ComObject PowerPoint.Application
$pres = $pp.Presentations.Open("경로\deck.pptx", -1, 0, 0)
$pres.Export("출력폴더", "PNG", 1280, 720)
$pres.Close(); $pp.Quit()
```

**pptx 편집 스킬 위치** (기존 PC 기준, 새 PC엔 재설치 필요):
`.../skills/pptx/scripts/` — `unpack.py`, `pack.py`, `add_slide.py`, `clean.py`.
새 PC에서는 `pip install python-pptx defusedxml` 후 동일 스크립트 사용 가능.

## 만약 뭘 하다 막히면

1. **작업 방향이 흔들리면** → `00.md` §1(관통 주장) 읽고 돌아오기.

4. **한꺼번에 다 안 되면** → sldIdLst에 슬라이드 하나씩만 남겨가며 어느 슬라이드가 문제인지 이등분 격리.
