### 1. 저장소 clone / pull
```bash

cd ai-agent-harness-docs && git pull
```

## 환경 재현 — 다른 PC에서 pptx 편집·QA에 필요한 것

**필수**:
- Python 3 + `python-pptx`
- PowerPoint (Office 16+) — 렌더 QA용 (COM 자동화)
- Git

**설치 명령**:
```bash
pip install python-pptx defusedxml
```

**PowerShell 렌더 스크립트** (재사용):
```powershell
$pp = New-Object -ComObject PowerPoint.Application
$pres = $pp.Presentations.Open("경로\deck.pptx", -1, 0, 0)
$pres.Export("출력폴더", "PNG", 1280, 720)
$pres.Close(); $pp.Quit()
```

**③덱 재빌드 스크립트**:
- 원본: `scratchpad/build_deck3.py` (python-pptx 기반)
- 실행 시 `03_실적용.pptx` 덮어쓰기 → PowerPoint COM으로 렌더 QA

4. **pptx 편집 후 PowerPoint COM이 파일 못 열면** → `<p:cxnSp>`에 line 아닌 preset 있는지 먼저 의심.
5. **stars 수치가 낡아 보이면** → GitHub 재확인, D5 §1-5 및 ③덱 슬라이드 2·3 갱신.
