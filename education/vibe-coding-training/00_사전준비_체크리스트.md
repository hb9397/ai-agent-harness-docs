## 5. 2안 개발 환경 (재난 주제도 지도 서비스)

> ⚠️ **Docker · PostgreSQL(PostGIS) · GeoServer는 교육 중 실제 사용 여부가 아직 미정입니다.**
> 다만 사용이 확정될 경우 당일 설치가 불가능하므로, **일단 설치·세팅까지만** 미리 해둡니다.

### 5-1. Docker Desktop (WSL2 포함)

- [ ] WSL2 확인
  - 확인: `wsl --version` → 버전 출력되면 OK
  - 없으면 설치: `wsl --install` 실행 후 **재부팅** (BIOS 가상화 활성화가 필요할 수 있음) **[실패 시 회신]**
- [ ] Docker Desktop 설치 가능 여부 확인 및 설치 (둘 중 하나) **[설치 불가 시 회신]**
  - 명령어: `winget install Docker.DockerDesktop`
  - 또는 공식 다운로드: https://www.docker.com/products/docker-desktop/
- [ ] 설치 후 Docker Desktop 실행 (트레이에 고래 아이콘이 안정되면 준비 완료)
- [ ] 확인: `docker --version` → 버전 출력되면 OK
- [ ] 동작 확인: `docker run hello-world` → "Hello from Docker!" 출력되면 OK
- [ ] 포트 충돌 확인: `netstat -ano | findstr "5432 8080"` → 아무것도 안 나오면 OK **[점유 중이면 회신]**

📷 (이미지 자리)

### 5-2. PostgreSQL (PostGIS 지원) 컨테이너 — ※ 사용 미정, 세팅만

- [ ] 마운트 폴더 생성
  - 명령어: `mkdir C:\edu\pgdata`
- [ ] 이미지 다운로드 (PostgreSQL 공식 이미지 기반 PostGIS 확장 이미지)
  - 명령어: `docker pull postgis/postgis:16-3.4`
- [ ] 컨테이너 생성·구동 (PowerShell에서 한 줄로 실행)
  - 명령어: `docker run -d --name edu-postgis -e POSTGRES_PASSWORD=edu1234 -p 5432:5432 -v C:\edu\pgdata:/var/lib/postgresql/data postgis/postgis:16-3.4`
- [ ] 구동 확인: `docker ps` → `edu-postgis`가 목록에 보이면 OK
- [ ] PostGIS 정상 확인: `docker exec -it edu-postgis psql -U postgres -c "SELECT PostGIS_Version();"` → 버전 문자열이 출력되면 OK **[실패 시 회신]**

📷 (이미지 자리)

### 5-3. GeoServer 컨테이너 — ※ 사용 미정, 세팅만

- [ ] 마운트 폴더 생성
  - 명령어: `mkdir C:\edu\geoserver_data`
- [ ] 이미지 다운로드 (GeoServer 공식 OSGeo 이미지)
  - 명령어: `docker pull docker.osgeo.org/geoserver:2.26.2`
- [ ] 컨테이너 생성·구동 (PowerShell에서 한 줄로 실행)
  - 명령어: `docker run -d --name edu-geoserver -p 8080:8080 -v C:\edu\geoserver_data:/opt/geoserver_data docker.osgeo.org/geoserver:2.26.2`
- [ ] 구동 확인: `docker ps` → `edu-geoserver`가 목록에 보이면 OK
- [ ] 접속 확인: 브라우저에서 http://localhost:8080/geoserver → 로그인 화면이 뜨면 OK (기본 계정 admin / geoserver) **[실패 시 회신]**

📷 (이미지 자리)

### 5-4. 브이월드 (vworld) — 접속 확인만

- [ ] 브라우저에서 https://www.vworld.kr 접속 가능 확인 **[차단 시 회신]**
