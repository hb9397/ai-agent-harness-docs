# Harness Kit v0.6.3

`0.6.3`은 프로젝트 instruction이 Harness Kit의 비기반 스킬을 필수 실행 체인으로
확대하던 문제를 바로잡는 패치다.

## 변경 사항

- `harness-setup`이 남기는 portable routing을 모든 설치 스킬·플러그인·일반 AI
  Agent가 따를 수 있는 producer 중립 계약으로 명확히 했다.
- Harness Kit 사용자 스킬의 project-local copy 금지를 `플러그인 스킬만 사용`으로
  해석하지 못하도록 `context-doc` 분석 규칙과 instruction 템플릿에 회귀 가드를 추가했다.
- `impl-reuse-scan`, `impl-verify`, `multi-review`, `doc-audit`, `frontend-design` 등
  비기반 스킬은 제공 선택지로 유지하되 필수 호출·완료 gate에서는 제거했다.
- 구현 계획·프로토타입·UI·모션 workflow는 선택한 producer와 무관하게 정규 경로,
  owner, 승인, 형식, evidence, prototype 비복사 계약을 유지한다.
- `humanize-korean` 후처리는 문서 생성 뒤 자동 제안하지 않고 사용자가 이번 요청에서
  문체 개선을 명시한 경우에만 proposal-only 흐름으로 진입한다.

## 유지되는 기반 흐름

- `harness-setup`
- `git-scoped-account`
- 선택형 `project-write-access`
- `design-doc` → `context-doc`

`harness-bootstrap`은 문서 없는 기존 코드베이스에서 위 기반 흐름을 묶어 실행하는 선택형
진입점으로 유지된다.

## 호환성

공개 스킬 이름, 앱 문서 정규 경로, `local/dev/prod` 실행 profile과 `dev/main` branch
기본 매핑, portable routing 형식은 유지된다. 기존 0.6.2 archive와 release는 변경하지
않는다.
