# Harness Kit v0.5.0 배포 후보 안내

`0.5.0`은 프로젝트 문서 쓰기 권한을 선택적으로 분리할 수 있도록 `project-write-access`를 사용자 플러그인에 포함한 버전이다. 일반 하네스 흐름에는 자동으로 끼어들지 않으며, 권한을 사용하는 프로젝트에서 검증된 관리자가 명시적으로 호출할 때만 설정·변경한다.

## 주요 변경

- 사용자 스킬 정본과 Codex·Claude runtime을 20종으로 맞췄다.
- GitHub·GitLab·Gitea용 CODEOWNERS, 로컬 pre-commit·pre-push 훅, Codex·Claude 쓰기 가드를 하나의 서명 정책에서 생성·검증한다.
- `admin`, `pm-pl`, 앱별 `app-doc-lead`, 일반 기여자의 `team` 쓰기 범위를 지원한다.
- `admin`이 앱 핵심 문서를 직접 수정할 때는 권한 전용 추가 확인을 요구한다.
- provider 서버의 브랜치 보호·필수 승인 규칙은 플러그인이 직접 변경하지 않고 외부 관리자 작업으로 남긴다.
