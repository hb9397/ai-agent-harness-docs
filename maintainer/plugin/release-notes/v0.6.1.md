# Harness Kit v0.6.1

`0.6.1`은 `design-doc`과 `context-doc`의 애플리케이션 문서 구조를 실제 프로젝트에서
점진적으로 구체화할 수 있도록 정리한 패치 릴리스 후보다. 스킬 이름, 호출 방식, 필수
입력, 산출물 경로와 설치 인터페이스는 `0.6.0`과 동일하다.

주요 변경 사항은 다음과 같다.

- `DESIGN.md`를 제목·요약, 개요, 구축 대상 기능 분류, 기술 스택, 아키텍처,
  애플리케이션 특이사항, 배포 환경, VSCode 익스텐션 추천 순서로 정규화한다.
- 최초 설계에서 기능을 과도하게 확정하지 않고 대분류만 기록하며, 갱신할 때 개발자가
  선택한 노드 Depth와 분류를 현재 사실 기준으로 반영한다.
- 기술 스택을 근거로 상위 아키텍처 패턴 후보와 패키지·파일 구조 예시를 제시하되,
  사용자가 선택하기 전에는 구현 강제 규칙으로 확정하지 않는다.
- 앱 컨텍스트를 10개 고정 섹션으로 정리하고 `DESIGN.md`의 개요·아키텍처·특이사항·
  구축 대상 기능 분류를 양방향으로 추적한다.
- 앱 컨텍스트의 핵심 도메인 개념을 계층형 애플리케이션 특이사항에 포함하고,
  실행 프로필·Git 원격과 브랜치·배포 방식·환경 변수·AI 구현 지침을 분리한다.
- 최초 instruction 세트는 공용 routing 계약을 제외하면 제목과 보편 목적만 있는 골격으로
  만들고, 현재 적용 근거가 생기면 규칙을 채우며 더 이상 필요하지 않은 파일은 승인 후
  컨텍스트 인덱스와 함께 제거한다.
- 앱 컨텍스트와 `*-instruction.md`에는 변경 이력을 쌓지 않고 현재 유효한 사실과 규칙만
  남긴다.
