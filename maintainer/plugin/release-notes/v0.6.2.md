# Harness Kit v0.6.2

`0.6.2`는 `context-doc`이 정보가 부족할 때 제시하는 실행 프로필과 환경별 브랜치의
기본 매핑을 실제 개발·운영 흐름에 맞게 조정한 패치 릴리스 후보다. 스킬 이름, 호출
방식, 필수 입력, 산출물 경로와 설치 인터페이스는 `0.6.1`과 동일하다.

주요 변경 사항은 다음과 같다.

- 기본 실행 프로필을 `local`, `dev`, `prod`로 제시한다.
- `local`은 로컬 개발, `dev`는 개발·검증 서버, `prod`는 운영 용도로 구분한다.
- 환경별 기본 브랜치는 `dev`, `main`으로 제시한다.
- `dev` 브랜치는 실행 프로필 `dev`, `main` 브랜치는 실행 프로필 `prod`에 대응시키고
  `main`을 운영 브랜치로 취급한다.
- `local`에는 환경별 브랜치를 배정하지 않으며 기존 `qa` 기본값은 제거한다.
- `harness-bootstrap`의 코드 관찰 결과 전달과 회귀검증도 같은 기본 매핑을 사용한다.
- 확인되지 않은 프로필과 브랜치를 실제 존재하는 값처럼 단정하지 않는 기존 안전 규칙은
  유지한다.

## 보호 자산 영향

- `skills/context-doc/templates/AGENTS.md.template`의 실행 프로필·브랜치 표를 수정했다.
- `context-doc`과 `harness-bootstrap`의 eval을 새 기본 매핑에 맞게 보완했다.
- 보호 자산의 삭제·이동·교체는 없다.

## 검증 상태

정적 계약 평가, 전체 스킬 회귀, source와 Codex·Claude runtime 동기화, 플러그인
manifest·archive 무결성, 결정적 이중 빌드와 Codex CLI 격리 설치 smoke를 통과했다.

못했고 앱의 실제 모델 호출 증적도 남아 있다. 릴리스 게이트는 `not-release-ready`이며,
tag와 GitHub Release는 이 변경에서 만들지 않는다.
