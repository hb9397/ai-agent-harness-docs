## 목적과 완료 정의

이 작업은 관리 저장소의 루트 운영문서 디렉터리 `Docs/`를 `.user-docs/`로
이전하고, 기존 문서·사용자 스킬 정본·관리자 스킬 정본·검증 스크립트에 남은
관리 저장소용 `Docs/` 참조를 새 경로로 정합화한다. 동시에 교육자료
`education/`을 저장소에서 제거하고, 변경된 정본으로 Codex·Claude 사용자
플러그인을 다시 생성해 기술적 정상 동작을 검증한다.

완료 상태는 다음 조건을 모두 만족해야 한다.

1. 루트 `Docs/`가 없고 `.user-docs/`에 기존 추적 파일 8개가 보존된다.
2. `education/`과 그 아래 추적 파일 10개가 저장소 작업 트리에서 제거된다.
3. 현재 효력을 갖는 문서·스킬·설정·검증 코드가 `Docs/`를 실행 경로로 사용하지
   않는다.
4. 사용자 프로젝트용 공개 산출물 경로 `.docs/**`는 한 글자도 변경하지 않는다.
5. 관리자 정본에서 projection을 재생성하고, 사용자 스킬 정본에서 Codex·Claude
   runtime을 재빌드한다. 생성물을 직접 편집하지 않는다.
6. 기존 `0.2.1` 아카이브와 기록된 SHA-256은 보존하고, 변경된 패키지는
   `0.2.2` PATCH 후보로 생성한다.
7. 링크·registry·projection·plugin validation·전체 eval·결정적 빌드·격리 CLI
   설치/삭제 smoke가 모두 통과한다.
8. 실제 모델 호출과 Desktop 앱 수동 증적이 없으면 기술 검증 성공과 별개로
   `release-ready`로 승격하지 않는다.

| 계층 | 편집 방법 | 대표 경로 |
|---|---|---|
| 루트·운영문서 정본 | 직접 수정 | `README.md`, `AGENTS.md`, `.user-docs/**`, `example/README.md` |

| 사용자 plugin runtime | builder로만 갱신 | `plugins/ai-agent-harness/runtime/**` |
| manifest·archive·release metadata | builder/검증기로만 갱신 | marketplace, plugin manifest, ZIP, `maintainer/plugin/**` |

  로컬 Markdown 링크 검사 대상 디렉터리

## 전역 주의사항

- `Docs` 또는 `docs`라는 단어를 저장소 전체에서 전역 치환하지 않는다. 경로
  리터럴 `Docs/`와 `./Docs/`만 파일별 의미를 확인해 변경한다.
- `.user-docs/`는 dot-directory이므로 탐색 명령에 `--hidden`을 사용한다.
- `improvement_plan/20260627/**`는 byte-preserve 대상이다. 그 안의 과거 `Docs/`
  표기는 잔존 허용 목록에 넣고 파일을 수정하지 않는다.
- `improvement_plan/20260729/**`, `improvement_plan/20260730/**`는 byte-preserve
  대상이 아니므로 현재 파일 경로를 가리키는 `Docs/` 리터럴을 `.user-docs/`로
  갱신한다. 과거 사실 자체를 설명하는 `education/**` 기준선 문장은 유지한다.
- 이 계획서 자체는 이전 경로와 삭제 대상을 설명하므로 `Docs/`와 `education/`
  문자열 잔존 허용 대상이다.
- `education/` 외의 파일을 삭제하지 않는다. 특히 보호 자산인 `example/`,
  `examples/`, `templates/`, `assets/`, `evals/`는 삭제·이동하지 않는다.
- `0.2.1`과 동일한 버전명으로 내용이 다른 ZIP을 만들지 않는다. 기존
  `plugins/ai-agent-harness-0.2.1.zip`과
  `ed5d08a52b99955b1b1d488ef3311161f011e8188d6e33253a9aa9c05e8b99cb`를
  보존한다.
- push, tag, GitHub release, upstream `released` lock 갱신은 이 작업 범위가
  아니다. 별도 승인 전 수행하지 않는다.
- Windows CLI smoke에서는 bare `codex`/`claude` 대신 실제 `.cmd` 경로를 JSON
  배열로 전달해 PowerShell command-resolution 오탐을 피한다.

### [INIT-01] · Git 기준선과 작업 트리 확인 (`repo root`)

**의존** : 없음

구현 직전 현재 브랜치, HEAD, 작업 트리, 원격 추적 상태를 확인한다. 작업 트리가
dirty이면 사용자 변경과 이번 작업을 구분할 수 있을 때만 진행한다.

```powershell
git status --short --branch
git rev-parse HEAD
git log -1 --oneline --decorate
git diff --check
git diff --cached --check
```

**검증 기준** : 기준 HEAD를 기록하고, 이번 작업 전에 존재한 변경을 덮어쓰지 않는다.

충돌로 간주하고 이동을 중단한다.

